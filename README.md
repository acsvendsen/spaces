# Spaces public viewer

Public demonstration build for spaces.proto.dk. Source, reference photos, saved owner layouts, native rendering and any later AI services remain in the private project.

Demo edits stay in your browser. Signed-in users can save private projects, reference images and renders on the Spaces server. Reusable furniture models are kept in a separate shared library. Export a layout for a portable copy. Explicit render requests use the Spaces rendering service; no owner credentials are distributed.

The owner approved the measured room model as the public demo. These are illustrative materials and lighting, not calibrated measurements.
